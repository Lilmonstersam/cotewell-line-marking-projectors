# Cotewell line marking projectors mock-up

Static category and product-page mock-ups for the Delta FieldLAS, Signum 75W and Signum 50W projectors.

## Local preview

Open `index.html` directly in a modern browser. No build step or package installation is required.

## GitHub Pages deployment

The workflow at `.github/workflows/deploy-pages.yml` deploys the repository root to GitHub Pages whenever a change is pushed to `main`. It can also be run manually from the Actions tab.

Before the first deployment:

1. Open the repository's **Settings**.
2. Select **Pages** under **Code and automation**.
3. Set **Source** to **GitHub Actions**.
4. Push the contents of this folder to the repository's `main` branch.

Expected site URL:

`https://lilmonstersam.github.io/cotewell-line-marking-projectors/`
